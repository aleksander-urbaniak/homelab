# 💻 Linux Monitoring Helpers

This folder contains monitoring agents and helper scripts that run on Linux hosts.

## Contents

- [prometheus/node-exporter](prometheus/node-exporter): Node Exporter install notes and scripts.
- [proxmox/pve-exporter](proxmox/pve-exporter): Proxmox PVE exporter user/token and deployment helpers.
- [loki/promtail](loki/promtail): Promtail install helper for shipping logs to Loki.
