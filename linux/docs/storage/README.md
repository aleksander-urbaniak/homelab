# 💻 Storage Runbooks

This folder contains storage maintenance guides for Linux VMs and hosts.

## Files

- [add-disk-mount.md](add-disk-mount.md): prepare a new disk, create a filesystem, mount it, and persist it in `/etc/fstab`.
- [expand-disk-online.md](expand-disk-online.md): expand an existing disk/partition/filesystem online, with notes for ext4 and related layouts.
