# 💻 Monitoring Scripts

This folder contains helper automation for monitoring workflows.

## File

- [uptime-kuma-push-monitor-tui.sh](uptime-kuma-push-monitor-tui.sh): interactive helper for creating an Uptime Kuma push monitor and installing a local checker.

The script expects credentials or session tokens at runtime. Do not commit generated monitor tokens or Uptime Kuma session secrets.
