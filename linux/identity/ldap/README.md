# 💻 LDAP Integration

This folder groups Authentik LDAP + SSSD integration by operating system family.

## Contents

- [debian](debian): Debian/Ubuntu integration script, usage notes, and local migration helper.
- [rhel](rhel): RHEL/Oracle/Rocky/Alma integration script and usage notes.

## Redaction

Public examples use `ldap.example.com`, `example.com`, and placeholder users. Real bind DNs, bind secrets, domains, and test users should remain private.
