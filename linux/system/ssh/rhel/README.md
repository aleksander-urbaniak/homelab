# 💻 RHEL SSH Configuration

This folder contains SSH examples for RHEL-family systems.

## Files

- [change-sshd-config.txt](change-sshd-config.txt): notes for changing the SSH daemon configuration.
- [generate-ssh-keys.txt](generate-ssh-keys.txt): SSH key-generation notes.
- [sshd_config](sshd_config): example SSH daemon configuration.

Do not commit generated private keys. Treat the snippets as examples to review before applying on a real host.
